# Проект: Резервное копирование Kubernetes-приложения в S3 (VK Cloud / MinIO) с помощью Velero

## Описание
Учебный проект по настройке резервного копирования и восстановления приложения (PostgreSQL + Persistent Volume) в кластере Kubernetes с использованием Velero и S3-совместимого хранилища.

## Структура
- `manifests/` — манифесты Kubernetes
- `src/` — Python-скрипты
- `scripts/` — Bash-скрипты
- `docs/` — технический отчет
